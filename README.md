# 2027 DSE 考試倒數

為香港中學生而設的 **2027 年香港中學文憑考試（HKDSE）** 靜態倒數網頁。頁面以 **中國語文** 為主要焦點，並列出考評局已確認日期的筆試科目。

語言：繁體中文（香港）`zh-Hant-HK`。純靜態 HTML／CSS／JS，無需後端。

## 本機開啟

### 方法一：直接開啟檔案

用瀏覽器打開專案根目錄的 `index.html`。

### 方法二：本機伺服器（建議）

在專案根目錄執行：

```bash
python3 -m http.server 8080
```

然後開啟 [http://localhost:8080](http://localhost:8080)。

用 Node.js 亦可：

```bash
npx --yes serve -l 8080
```

## 頁面內容

- 主畫面倒數：**中國語文（一）及（二）**，目標時間為 **2027年4月8日（星期四）上午 8 時 30 分（香港時間）**。
- 倒數每秒更新，單位為 **天／時／分／秒**。科目開考後會改為平靜的「已考完」，不會出現負數。
- 下方列出其他 **已確認日曆日期** 的筆試。英語文學、科技與生活、體育、音樂等尚未落實日期的科目，以及實習／口試時段、後備日，都不會顯示。

## 編輯考試日期

所有考試日期集中在 [`js/config.js`](js/config.js)。

- 時區：`Asia/Hong_Kong`
- 上午場次預設：`08:30:00`
- 若考評局更新時間表，只需改該檔的 `date`／`startTime`／科目名稱

倒數計算在 [`js/countdown.js`](js/countdown.js)，與畫面邏輯分開，方便核對。

核對設定與倒數邏輯：

```bash
node tests/verify.mjs
```

## GitHub Pages

本倉庫只提供靜態檔案，方便之後用 GitHub Pages 發布。**發布流程由另一個代理／流程處理**，請不要在此專案設定 Vercel 或 Netlify。
